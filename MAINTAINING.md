# Maintain the marketplace

The plugin bundle is generated by Aguru's builder-kit build. Treat bundled documentation, schemas, skills and scripts as release artifacts; change their source in the builder-kit project and rebuild instead of maintaining independent copies here.

## Publish an update

1. In an authorized checkout of the builder-kit source, update the shared kit version and run `pnpm --filter @aguru/builder-kit build`.
2. Copy the contents of the generated `builder-kit/build/dist/aguru-codex-plugin/` into this repository's `plugins/aguru-workflow-builder/`, replacing the previous bundle completely. Include hidden workspace files, and remove the bundle's nested `.agents/` marketplace; the repository root owns the catalog.
3. Restore the public plugin README from this repository, then check that the demo's README links still resolve. Copy the generated LICENSE to the repository root. Keep the public installation instructions aligned with supported clients.
4. Check the version, referenced assets, license notices, source leak checks, links, credential exclusion and absence of test files. Verify an extracted bundle creates a fresh workspace and rejects an existing destination. Install its dependencies and validate the shipped workflow templates.
5. Test marketplace registration and plugin installation using an isolated Codex configuration, then exercise registration from GitHub after pushing.
6. Commit using Conventional Commits, tag the version, and publish a GitHub release with a ZIP of the complete marketplace (including `.agents/` and `plugins/`) and its SHA-256 checksum. Do not reuse a released version for changed plugin contents.

The standalone npm package and this GitHub marketplace are separate distributions. Publishing one does not update the other. This marketplace does not imply approval or listing in OpenAI's public Plugins Directory.
