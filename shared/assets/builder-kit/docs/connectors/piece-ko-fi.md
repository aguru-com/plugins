# Ko-fi

Receive triggers for donations, subscriptions, commissions, and shop orders from Ko-fi.

```yaml
type: activepiece
with:
  piece: '@activepieces/piece-ko-fi'
  version: '0.0.5'
```

Categories: PAYMENT_PROCESSING. See [the connector list](README.md) for how authentication and limits work.

## Authentication

### `SECRET_TEXT`: Verification Token

> Your Ko-fi webhook verification token. Find it in Ko-fi Dashboard > Settings > API/Webhooks > Advanced Settings > Webhook verification token.

## Actions

None.
