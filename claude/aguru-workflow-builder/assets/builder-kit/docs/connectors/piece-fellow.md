## Actions

### `get-note`

**Get AI Note.** Fetches a single Fellow AI meeting note by its note ID. Use to read the content of a known note when you already have its ID (e.g. from a recording or a prior step). Requires the exact note ID; read-only and idempotent. Needs authentication.

Kind: read, safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `noteId` | string | yes |  | Note ID. |

### `custom_api_call`

**Custom API Call.** Make a custom API call to a specific endpoint. Needs authentication.

Kind: write.

| Input | Type | Required | Default | Notes |
