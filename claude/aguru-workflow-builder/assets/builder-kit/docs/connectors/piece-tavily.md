# Tavily

Search engine tailored for AI agents.

```yaml
type: activepiece
with:
  piece: '@activepieces/piece-tavily'
  version: '0.3.2'
```

Categories: ARTIFICIAL_INTELLIGENCE. See [the connector list](README.md) for how authentication and limits work.

## Authentication

### `SECRET_TEXT`: API Key

>

> 2. Log in and navigate to your dashboard.
> 3. Locate and copy your API key from the dashboard.

## Actions

### `search`

**Search.** Run a web search through the Tavily search engine for a natural-language query and return relevant results; tune scope with search depth, a general vs. news topic, recency windows, and domain include/exclude lists, and optionally include images, raw page content, or an LLM-generated answer summary. Use to look up current or external information from the web. Read-only and idempotent: the same query returns equivalent results without side effects, though live web data may shift over time. Needs authentication.

Kind: search, safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `query` | string | yes |  | Search Query. The search query you want to execute with Tavily. |
| `search_depth` | string | no | `"basic"` | Search Depth. The depth of the search. It can be "basic" or "advanced". One of `"basic"`, `"advanced"`. |
| `topic` | string | no | `"general"` | Topic. The category of the search. This will determine which of our agents will be used for the search. One of `"general"`, `"news"`. |
| `days` | number | no | `3` | Days. The number of days back from the current date to include in the search results. Only available when using the "news" search topic. Default is 3. |
| `time_range` | string | no |  | Time Range. The time range back from the current date to include in the search results. One of `"day"`, `"week"`, `"month"`, `"year"`, `"d"`, `"w"`, `"m"`, `"y"`. |
| `max_results` | number | no | `5` | Maximum Results. The maximum number of search results to return. |
| `include_images` | boolean | no | `false` | Include Images. Include a list of query-related images in the response. |
| `include_image_descriptions` | boolean | no | `false` | Include Image Descriptions. When include_images is set to True, this option adds descriptive text for each image. |
| `include_answer` | boolean | no | `false` | Include Answer. Include a short answer to original query, generated by an LLM based on Tavily's search results. |
| `include_raw_content` | boolean | no | `false` | Include Raw Content. Include the cleaned and parsed HTML content of each search result. |
| `include_domains` | array | no |  | Include Domains. A list of domains to specifically include in the search results. |
| `exclude_domains` | array | no |  | Exclude Domains. A list of domains to specifically exclude from the search results. |

Output fields:

- `query`: Query
- `follow_up_questions`: Follow Up Questions
- `answer`: Answer
- `images`: Images
- `results`: Results
- `results[].url`: URL (url)
- `results[].title`: Title
- `results[].content`: Content
- `results[].score`: Score (number)
- `results[].raw_content`: Raw Content
- `results[].id`: ID
- `response_time`: Response Time (number)
- `request_id`: Request ID

### `extract`

**Extract Content.** Fetch and return the cleaned, parsed content of one or more specific web pages by passing their URLs, optionally including images found on those pages. Use when you already have exact URLs (e.g. from a prior search) and need their full text rather than performing a new query. Read-only and idempotent: repeating the call with the same URLs has no side effects. Needs authentication.

Kind: read, safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `urls` | array | yes |  | URLs. The URLs you want to extract with Tavily. |
| `include_images` | boolean | no | `false` | Include Images. Include a list of images extracted from the URLs in the response. |

Output fields:

- `results`: Results
- `results[].url`: URL (url)
- `results[].title`: Title
- `results[].raw_content`: Raw Content
- `results[].images`: Images
- `failed_results`: Failed Results
- `failed_results[].url`: URL (url)
- `failed_results[].error`: Error
- `response_time`: Response Time (number)
- `request_id`: Request ID

### `tavily_crawl_website`

**Crawl Website.** Explore a website starting from a root URL, following links up to a depth and breadth limit, and return the extracted content of each page visited. Use to gather content across a whole site or section rather than a single page. Use `tavily_map_website` instead when only the URL structure is needed, not page content. Not idempotent: page content and the set of URLs discovered can change between runs. Needs authentication.

Kind: search, not safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `url` | string | yes |  | Root URL. The root URL to begin the crawl from. |
| `instructions` | string | no |  | Instructions. Natural language instructions describing what the crawler should look for. |
| `max_depth` | number | no | `1` | Max Depth. How far from the root URL the crawler can explore. Range: 1-5. |
| `max_breadth` | number | no | `20` | Max Breadth. Maximum number of links to follow per level of the tree. Range: 1-500. |
| `limit` | number | no | `50` | Limit. Total number of links the crawler will process before stopping. |
| `select_paths` | array | no |  | Select Paths. Regex patterns selecting only URLs with these path patterns. |
| `select_domains` | array | no |  | Select Domains. Regex patterns selecting only specific domains or subdomains. |
| `exclude_paths` | array | no |  | Exclude Paths. Regex patterns excluding URLs with these path patterns. |
| `exclude_domains` | array | no |  | Exclude Domains. Regex patterns excluding specific domains or subdomains. |
| `allow_external` | boolean | no | `true` | Allow External Links. Include external domain links in the final results list. |
| `include_images` | boolean | no | `false` | Include Images. Include images found on the crawled pages. |
| `extract_depth` | string | no | `"basic"` | Extract Depth. The depth of content extraction per page. One of `"basic"`, `"advanced"`. |
| `format` | string | no | `"markdown"` | Format. The format of the extracted page content. One of `"markdown"`, `"text"`. |

Output fields:

- `base_url`: Base URL (url)
- `results`: Results
- `results[].url`: URL (url)
- `results[].raw_content`: Raw Content
- `response_time`: Response Time (number)
- `request_id`: Request ID

### `tavily_map_website`

**Map Website.** Explore a website starting from a root URL, following links up to a depth and breadth limit, and return the list of URLs discovered — no page content. Use to discover a site's structure or find candidate URLs to pass to `tavily_extract` or `tavily_crawl_website`. Not idempotent: the set of URLs discovered can change between runs. Needs authentication.

Kind: search, not safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `url` | string | yes |  | Root URL. The root URL to begin the mapping from. |
| `instructions` | string | no |  | Instructions. Natural language instructions guiding the crawler. |
| `max_depth` | number | no | `1` | Max Depth. How far from the root URL the crawler can explore. Range: 1-5. |
| `max_breadth` | number | no | `20` | Max Breadth. Maximum number of links to follow per level of the tree. Range: 1-500. |
| `limit` | number | no | `50` | Limit. Total number of links the crawler will process before stopping. |
| `select_paths` | array | no |  | Select Paths. Regex patterns selecting only URLs with these path patterns. |
| `select_domains` | array | no |  | Select Domains. Regex patterns selecting only specific domains or subdomains. |
| `exclude_paths` | array | no |  | Exclude Paths. Regex patterns excluding URLs with these path patterns. |
| `exclude_domains` | array | no |  | Exclude Domains. Regex patterns excluding specific domains or subdomains. |
| `allow_external` | boolean | no | `true` | Allow External Links. Include external domain links in the final results list. |

Output fields:

- `base_url`: Base URL (url)
- `results`: Results
- `response_time`: Response Time (number)
- `request_id`: Request ID

### `tavily_start_research_task`

**Start Research Task.** Queue a background research task that investigates a topic or question in depth and returns a request id. The task runs asynchronously; poll its result with `tavily_get_research_task` using the returned request id. Use for comprehensive, multi-source research beyond what a single search covers. Not idempotent: every call starts a new task. Needs authentication.

Kind: write, not safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `input` | string | yes |  | Research Question. The research task or question to investigate. |
| `model` | string | no | `"auto"` | Model. "mini" for targeted research, "pro" for comprehensive multi-angle analysis. One of `"auto"`, `"mini"`, `"pro"`. |
| `citation_format` | string | no | `"numbered"` | Citation Format. Citation style used in the report. One of `"numbered"`, `"mla"`, `"apa"`, `"chicago"`. |
| `output_length` | string | no | `"standard"` | Output Length. Target size of the response. One of `"short"`, `"standard"`, `"long"`. |
| `include_domains` | array | no |  | Include Domains. Soft preference domains; research prioritizes these. Max 20. |
| `exclude_domains` | array | no |  | Exclude Domains. Hard blocklist; no URLs from these domains appear. Max 20. |

Output fields:

- `status`: Status
- `input`: Input
- `model`: Model
- `created_at`: Created At (datetime)
- `response_time`: Response Time (number)
- `request_id`: Request ID

### `tavily_get_research_task`

**Get Research Task.** Read the status and, once finished, the content and sources of a research task started with `tavily_start_research_task`. Status is one of pending, in_progress, completed, or failed; only a completed task carries content and sources. Use to poll a previously started research task. Read-only and idempotent. Needs authentication.

Kind: read, safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `request_id` | string | yes |  | Request ID. The request id returned by Start Research Task. |
| `include_usage` | boolean | no | `false` | Include Usage. Include credit usage information in the response. |

Output fields:

- `content`: Content
- `sources`: Sources
- `sources[].url`: URL (url)
- `sources[].title`: Title
- `sources[].favicon`: Favicon (url)
- `status`: Status
- `created_at`: Created At (datetime)
- `usage`: Usage
- `usage.credits`: Credits (number)
- `response_time`: Response Time (number)
- `request_id`: Request ID
