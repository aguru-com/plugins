# Pdfcrowd

Convert web pages and HTML to PDF with advanced formatting options

```yaml
type: activepiece
with:
  piece: '@activepieces/piece-pdfcrowd'
  version: '0.2.1'
```

Categories: CONTENT_AND_FILES. See [the connector list](README.md) for how authentication and limits work.

## Authentication

### `BASIC_AUTH`: Pdfcrowd Credentials

> Your Pdfcrowd API credentials. Get them at https://pdfcrowd.com/user/account/

## Actions

### `url_to_pdf`

**Convert URL to PDF.** Render a publicly accessible web page URL into a PDF file via the Pdfcrowd API, returning the generated document. Choose this when the source is a live URL rather than raw HTML markup (use Convert HTML to PDF for an HTML string). Supports extensive layout, header/footer, watermark, and security options. Not idempotent: each call performs a fresh conversion that produces a new file and consumes account credits. Needs authentication.

Kind: read, not safe to repeat.

### `html_to_pdf`

**Convert HTML to PDF.** Render a raw HTML string into a PDF file via the Pdfcrowd API, returning the generated document. Choose this when you already have HTML markup (e.g. a generated invoice or report) rather than a live page URL (use Convert URL to PDF for a URL). Supports extensive layout, header/footer, watermark, and security options, plus template data injection. Not idempotent: each call performs a fresh conversion that produces a new file and consumes account credits. Needs authentication.

Kind: read, not safe to repeat.
