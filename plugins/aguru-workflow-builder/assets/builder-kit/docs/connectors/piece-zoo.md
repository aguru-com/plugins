# Zoo

Generate and iterate on 3D models from text descriptions using ML endpoints.

```yaml
type: activepiece
with:
  piece: '@activepieces/piece-zoo'
  version: '0.1.8'
```

Categories: ARTIFICIAL_INTELLIGENCE. See [the connector list](README.md) for how authentication and limits work.

## Authentication

### `SECRET_TEXT`: API Key

> Your Zoo API Key (Bearer Token).

## Actions

### `generate_cad_model`

**Generate CAD Model.** Submit a text prompt to Zoo's text-to-CAD ML model to generate a new 3D model in a chosen export format (FBX, GLB, GLTF, OBJ, PLY, STEP, or STL). Each call starts a new generation job, so it is not idempotent. Optionally include KCL source in the output; retrieve finished results with the get CAD model action. Needs authentication.

Kind: read, not safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `outputFormat` | string | yes |  | Output Format. One of `"fbx"`, `"glb"`, `"gltf"`, `"obj"`, `"ply"`, `"step"`, `"stl"`. |
| `outputKcl` | boolean | no |  | Include KCL Output. |
| `prompt` | string | no |  | Prompt. |

### `kcl_completions`

**KCL Code Completions.** Generate KCL (Zoo Kernel Configuration Language) code completions from a prompt using Zoo's ML model. Pick when authoring or extending KCL scripts for CAD geometry. Output varies between calls (non-deterministic) and is tunable via temperature, max tokens, and stop sequences. Needs authentication.

Kind: read, not safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `prompt` | string | yes |  | Prompt. The KCL code prompt to get completions for. |
| `temperature` | number | no |  | Temperature. Controls randomness in completion generation (0.0 to 1.0) |
| `maxTokens` | number | no |  | Max Tokens. Maximum number of tokens to generate. |
| `stop` | array | no |  | Stop Sequences. Sequences where the API will stop generating further tokens. |

### `text_to_cad_iteration`

**Iterate CAD Model.** Generate a new CAD model iteration from a text prompt describing desired changes. Use to refine or evolve a design via natural language; to rate an existing result instead, use give-model-feedback. Not idempotent: each call starts a fresh generation, so avoid blind retries. Needs authentication.

Kind: write, not safe to repeat.

| Input | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `prompt` | string | yes |  | Prompt. The prompt describing desired changes. |

### `give_model_feedback`

### `get_center_of_mass`

**Get Center of Mass.** Compute the center-of-mass coordinates of a 3D solid from an uploaded CAD file (FBX, GLB, glTF, OBJ, PLY, STEP, or STL). Read-only analysis that does not modify the file and returns the same value for the same input. Needs authentication.

Kind: read, safe to repeat.
